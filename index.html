Rules
  • QR: starting grid → race result.
  • PG: grid − finish (position gain). PGNN: negatives count as 0.
  • PGC: top 10 gainers per event score 25-18-15… points; ties split slot points, tiebreak by real finish.
  • PGNS: same but no split — straight positional points.
  • Reverse: classified finishers scored back-to-front (last gets 25), no DNFs.
  • Data: Jolpica F1 API (live calendar + results).
