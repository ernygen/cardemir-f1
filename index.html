Nasıl çalışıyor? Excel → site → F1 API geçişi
  1. Şimdi: python excel_to_json.py komutu F126.xlsx dosyasını okuyup data.json üretir. Site sadece bu JSON'u okur.
  2. Excel güncellenince scripti tekrar çalıştır + sayfayı yenile. Bu kadar.
  3. Yarın: config.js içinde DATA_SOURCE = "f1api" yap. providers/f1ApiProvider.js içindeki örnek Jolpica kodunu aç. Arayüz kodu değişmez.

Not: Drivers/Teams sheet'lerinde sadece ilk blok okunur (ilk boş satıra kadar). Altaki kümülatif/motor blokları bilerek atlanır.
